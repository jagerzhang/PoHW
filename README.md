# PoHW — Proof of Homework

> 给 Android 电视加一道门槛：**到点弹出一道题，答对才能继续看**。
> 一个不上架应用商店、供家长自行侧载的家庭小工具，默认离线可用、不访问互联网。

| --- | --- |

| 运行平台 | Android TV / 电视盒子，`minSdk 21`，遥控器操作 |

## 它能做什么

- **跨应用全屏答题遮罩**：守护服务在后台计时，到点把一道四选一题盖在任意界面之上；答对才放行，遮罩吞掉媒体键与返回键。
- **答错两次自动换题**：同一题连错 2 次原地换题，并写入独立的错题库（`pohw_wrong.db`），家长可翻页查看、删除或清空。
- **内置 3,989 题离线题库**：`assets/quiz.db` 随 APK 发布，首次启动复制到本地数据库，之后只读、零网络；每题带 1–6 年级标签与难度分档（默认不限），另有按年级分档的参数化算式生成器兜底。
- **练习模式**：控制台「练习模式」进入独立全屏自由答题页，可切学科 / 年级 / 难度，答对自动出下一题并显示统计；练习期间挂起守护弹题，退出自动恢复。
- **年级防超纲**：抽题每一层都带年级上限，只抽不高于当前年级的题；`tests/bank_quality_check.py` 把年级标签、英文空格、重复题与超纲规则固化进自动审核。
- **答对自动继续**（默认开）：达到解锁门槛后直接关闭答题页，无需再按一次「继续观看」。
- **四槽学科配比**：数 / 语 / 英 / 其他默认 `5:3:2:2`，`0–5` 可调；开启「全学科」才加入第 4 槽，且题库确实有非三科题时才生效。
- **学习进度（方案 B）**：按「上册 / 下册」与「已学到第 N 单元」限制出题范围，解决「刚开学却抽到整学年题」的问题，详见下一节。
- **家长设置 + PIN**：首次进入设置要求初始化 4–8 位数字密码（PBKDF2 + 随机盐），关闭守护需就地验证密码，界面不退出。
- **答题时暂停 / 恢复播放**：音频焦点 + 媒体键请求播放器暂停，答完尝试恢复（best-effort，见「已知边界」）。
- **启动即守护**：APP 冷启动自动拉起守护（默认开）；开机自启默认关，需家长自行打开并放行厂商自启动权限。
- **错题库、统计与打赏**：首页看答对率与最近错题；设置页有静态收款码页（微信 / 支付宝，遥控器左右切换），无支付 SDK、无订单、无联网。

## 它不能做什么

- 不是家长控制 / 设备锁 / 应用锁，也不阻止卸载、不阻止用其他设备看视频。
- 不联网收集任何数据；`INTERNET` 权限仅供家长**自行配置**的可选在线题库源，地址为空时一次请求都不发。
- 不控制第三方视频 App 的播放状态，暂停/恢复是尽力而为的系统级请求。
- 不是教材同步练习题库：题目由按课标自编的题与整理自公开渠道、逐题校验清洗后的题组成，不含出版社真题。

## 快速开始（U 盘安装，不需要电脑连电视）

1. **拿到 APK**：到 [官网下载页](https://pohw.zhangge.net/#download) 直接下载最新版（历史版本见 [Releases](https://github.com/jagerzhang/PoHW/releases/latest)），或按下方「构建」自行出包。
2. **拷进 U 盘**：把 APK 文件复制到 U 盘（FAT32 / exFAT 均可）。
3. **电视上安装**：U 盘插到电视 USB 口 → 打开电视自带的「文件管理器」→ 找到 APK 点击安装；首次安装若提示「未知来源」，按系统提示允许即可。
4. **授权悬浮窗**：打开 APP，点「授权悬浮窗」，在系统设置里允许「显示在其他应用上层」。
5. **家长设置**：首次进入会要求初始化 4-8 位数字密码；设好年级 / 出题频率 / 学科配比 / 学习进度，点「保存并返回」。
6. **开启守护**：回首页点「开启守护」，按 Home 切到任意视频 App，到点会弹题。

已有旧版时**直接覆盖安装**即可（同一签名证书 + `versionCode` 递增），家长密码、设置与错题库都会保留。
忘记密码：在电视「设置 → 应用管理 → PoHW → 清除数据」重置（会清空设置、统计与错题库）；
遮罩卡住卸载流程时，在同一页面点「强制停止」，或先关闭守护。

## 学习进度与年级过滤

当前题库经 v1.2.3 重建后，每题都有明确的 **1–6 年级标签**，但**不含教材版本、
学期（`term`）与单元序号**（全库 `term` 为空）。家长需要知道三件事：

| 设置项 | 取值 | 默认 | 实际效果 |
| --- | --- | --- | --- |
| 所在年级 | 小学 1–6 / 初中 1–3（内部 1–9） | 三年级 | 抽题时附加 `grade<=?`，**只抽不高于该年级的题** |
| 学习学期 | 全学年 / 上册 / 下册 | 全学年 | 题库无学期数据，退化为按年级 / 学科过滤 |
| 已学单元 | 不限 / 第 1…N 单元 | 不限 | 新库无单元序号，同样退化为年级 / 学科过滤 |

- **年级防超纲**：`QuizDb` 的四个池谓词、最后一层保底查询与两个计数方法都带
  `grade<=?`。空池时只依次放宽学期与单元，**任何一层都不会放宽年级上限**，
  也不会为了凑题换学科。
- **课标重标定**：不再信任题面自带的年级标签（曾把代数等式标成三年级），改为按
  小学课标知识点白名单逐题判级；只有明确且单纯命中 1–3 年级课标的题才进低年级池，
  其余保守标到 4 年级以上。规则固化在 `tests/bank_quality_check.py`，
  重建脚本见 `tools/quizbank/rebuild_bank.py`。
- **进度表保留**：`app/assets/syllabus.json` 覆盖小学 1–6 年级数学 × 上/下册 =
  12 册、105 个有序单元、134 个别名，供旧数据兼容与结构校验；对新库不再产生
  精确单元过滤。`build_syllabus.py --check` 仍作为门禁运行。
- **升级安全**：三个设置默认值不变，覆盖安装不改变原有抽题范围。

## 练习模式

控制台第 1 行第 2 个按钮（原「立即出题」）是「练习模式」，点击进入独立全屏自由答题页：顶部可切
学科（数学 / 语文 / 英语 / 混合）、年级（1–9）、难度（不限 / 低 / 中 / 高），
中间四选一答题（方向键 + 确定键，或数字键 1–4），答对即时反馈并自动出下一题，
底部显示已练 / 正确 / 连对统计；「换一题」和返回键随时可用。

进入练习页会**挂起守护弹题**，退出后自动恢复。守护服务本身不停止，因此练习模式
不会变成零成本绕过口子；即使练习页被强制关闭，服务恢复运行后守护照常计时。
练习参数保存在 `PracticeConfig`，与家长设置里的守护参数完全隔离。

「授权悬浮窗」按钮已恢复在控制台第 2 行第 1 个，点击直接打开系统授权页；「家长设置 → 03 开机与播放」也保留同样入口，与开机自启、厂商自启动设置放在一起。

## 内置题库、难度与许可证

`app/assets/quiz.db` 含 4 张表、**3989 道题**，全部带 1–6 年级标签与难度分档。
题目由本项目按课标自编的低年级题，与整理自互联网公开渠道、经逐题校验清洗后的题目组成；
当前库先由 `tools/quizbank/rebuild_bank.py` 完成课标重标定，再由 `tools/quizbank/apply_review.py` 按逐题处置台账落地复核结果；台账与补题源文件在 `tools/quizbank/review/`，可从 bank-v4 完整复现。

| 1 | 137 | 76 | 121 | 334 | 334 |
| 2 | 164 | 48 | 26 | 238 | 572 |

| 4 | 985 | 173 | 286 | 1444 | 2604 |

**年级防超纲**：`QuizDb` 的四个池谓词与最后一层兜底都带 `grade<=?`，只抽不高于当前年级的题；
无课标关键词可判级的题一律保守标到 4 年级以上。`tests/bank_quality_check.py` 把年级标签、
英文单词空格、重复题、超纲关键词与累积池题量固化进自动审核门禁。

**题目难度**：每题带 `difficulty`（公开难度系数或原创映射）与 `difficulty_level`（低 / 中 / 高）。
家长可设「题目难度」，默认**不限**；选择后做 **80/20 倾向加权**（约 80% 从所选档抽、20% 走全库），
因为站点系数是众包「点击修正」值，同一道题常被标成不同难度，不适合硬过滤。

**题库来源**：部分题目整理自互联网公开渠道，经逐题校验与清洗后用于家庭学习场景；
低年级题目由本项目按课标自编。本项目为个人非商业的家庭自用工具，代码部分沿用 MIT 许可证，
题库内容的权利归各自权利人所有，不随 MIT 许可证一并授权。
**如相关内容涉及版权或其他权益问题，请通过 GitHub Issue 联系维护者，核实后会及时删除或替换。**
完整说明见 [docs/DATA_SOURCES.md](docs/DATA_SOURCES.md)。构建时 `tools/quizbank/verify.py`
会重算算式、逐题校验选项、校验 meta 与难度分档、做篡改检测；
`tests/bank_quality_check.py` 另查年级标签、英文单词空格、重复题与超纲关键词。

> 新题库没有学期 / 教材单元信息，因此「学习学期 / 已学单元」对绝大多数题不生效，
> 会退化为按年级 / 学科过滤；`syllabus.json` 仍保留供旧数据兼容。

在线题库源是**可选预留**：家长填了自己的 `index.json` 地址后才会按周期联网，默认关闭。

## 构建

零 Gradle：`aapt2 → javac → d8 → zipalign → apksigner`，需要 JDK 17 与 Android SDK 34。

```bash
JAVA_HOME=/opt/jdk17 ANDROID_HOME=/path/to/sdk \
POHW_KEYSTORE=/path/to/debug.keystore POHW_KEYSTORE_PASS=android \
bash app/build.sh
```

**签名硬门禁**：`build.sh` 会从成品 APK 读取证书 SHA-256，与已发布证书
`76eb6063b574…26172` 比对，不一致直接失败。用错 keystore 会导致电视上覆盖安装失败，
所以这一步不依赖人记得传环境变量。本地实验构建须显式 `POHW_ALLOW_DEV_SIGN=1`。
完整说明见 `docs/BUILD.md`。

版本策略：`versionName` 语义化（当前 1.2.7），`versionCode` 单调递增（当前 43）且**不随展示版本重置**，
否则已安装旧版的设备会报 `INSTALL_FAILED_VERSION_DOWNGRADE`。同一版本线内的内部构建不单独发 Release。

## 验证与门禁

`bash app/build.sh` 的 `[0/9]` 会先跑完下面 5 组检查，任何一条失败都不会出包：

| 检查 | 当前结果 | 守什么 |
| --- | --- | --- |
| `tests/layout_contract.py` | **211** 条 | 3×2 首页、单列设置、焦点链、证书门禁、方案 B 全链路，以及发布版本口径 / 四项可选加固默认值 / CI |
| `tests/bank_distribution_check.py` | `BANK_DISTRIBUTION_OK` | 用真实 SQL 复刻四槽配比、池隔离与池保持兜底 |
| `tools/quizbank/build_syllabus.py --check` | `SYLLABUS_CHECK_OK books=12` | 进度表与题库同源、无遗漏别名 |
| `tests/study_scope_check.py` | `STUDY_SCOPE_OK` | 学期/单元范围不外溢、空池逐层放宽顺序、默认行为兼容 |
| `tests/run.sh` | **308** 项 JVM 单测（13 组） | PIN、按键时序、启动策略、权重、JSON / Syllabus、设置默认值 |

发布前另跑 `python3 tests/mutation_suite.py`：故意回退 75 处实现，再加 1 次不带发布密钥构建（76/76），
确认门禁每一处都能拦下，最后校验源码哈希完全恢复并用发布密钥重建 `dist/`。

## 发布流程

所有改动都走分支与审核，不再直接推 `main`：

1. 从 `main` 拉 `feat/*` 或 `feature/*` 分支，改动与门禁脚本一起提交。
2. 推分支并开 **Pull Request** 到 `main`。
3. `.github/workflows/ci.yml` 作为「自动审核」：跑源码契约、JVM 单测、题库/进度/配比回归，并用开发密钥完整构建一次 APK（CI 不持有发布密钥）。
4. `auto-review` 检查通过后才能合入 `main`；分支保护要求 PR + 该检查。
5. **tag 与 Release 由维护者另行指定**：确认后再用同一 release keystore 出包、打 tag、上传 APK 与 `PoHW-src.zip`。

对外发布 11 个正式 Release：`v1.0.0`（versionCode 12）、`v1.0.1`（13–17）、
`v1.0.2`（18–21）、`v1.2.0`（25–28）、`v1.2.1`（29–31）、`v1.2.2`（33）、`v1.2.3`（35）、`v1.2.4`（37）、`v1.2.5`（39）、`v1.2.6`（41）、`v1.2.7`（43）；`v1.1.0` 为未发布开发版本线，成果由 v1.2.0 承接。
官网版本记录与 GitHub Releases 一一对应。
`v1`–`v6` 开发期迭代归档为 `v0.9.0-re`，不对应任何可下载资产。

## 已知边界 / FAQ

- **暂停视频是 best-effort**：靠音频焦点 + 媒体键请求，不保证所有视频 App 响应；小米等 ROM 的自启动权限也需家长手动放行。
- **题库不是教材同步练习**：新题库已剔除纲目定位题，但仍无出版社版本、无单元序号；学习进度设置对新题库基本退化为按年级过滤。
- **难度是倾向不是保证**：站点难度系数噪声大（严格同题比对下 83% 的重复组难度值不一致），选「高」仍可能遇到偏易题。
- **题库来源与版权**：见 `docs/DATA_SOURCES.md`；如有侵权请通过 GitHub Issue 联系删除。
- **全学年不能选单元**：需要先选上/下册，否则单元按钮会自动禁用。
- **真机待确认**：不同 ROM 的悬浮窗权限、`HIDE_OVERLAY_WINDOWS`、字体 150% 下的长文案、二维码远距离可扫、DPAD 切渠道。
- **覆盖安装**：务必使用同一签名证书；换 keystore 只能先卸载，会丢设置与错题库。
