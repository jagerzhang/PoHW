# 题库数据来源说明

PoHW 内置题库中的部分题目整理自互联网公开渠道，经逐题校验、清洗与统一编号后
用于本项目的家庭学习场景；另有部分题目由本项目按小学课标参数化自编。
题目正文、选项与解析均不含站点水印、外链或抓取标记。

本项目为个人非商业的 Android TV 家庭实验，不上架任何应用商店、不用于商业用途。
我们尊重原作者与内容权利人的合法权益：**如相关内容涉及版权或其他权益问题，
请通过本仓库的 GitHub Issue 联系维护者**，核实后会及时删除或替换相关内容。

## 题目构成

| 类别 | 说明 |
| --- | --- |
| 课标知识点四选一 | 按教材册次、单元与课标知识点组织的标准四选一题 |
| 解析与难度 | 每题带讲解，难度按同年级同学科的题面复杂度分三档 |

题库共 **9544 道**，全部带 1–6 年级标签与真实教材册次（上 / 下册）。
`grade` 为教材年级；每题还带教材版本族、单元序号与课标知识点，
家长可按年级、上下学期与已学单元设定出题范围。小学英语三年级起点，
1–2 年级没有英语题。`difficulty` / `difficulty_level` 按题面复杂度分三档。

家长可设置难度倾向，默认「不限」。抽题时只取不高于当前年级的题目，
避免低年级出现超纲内容；空池依次放宽单元 → 学期 → 年级，始终不换学科。
`app/assets/quiz.db` 的 `meta` 表记录了版本戳、题数与来源说明；
重建与校验口径见 [QUESTION_BANK.md](QUESTION_BANK.md)。
