# 题库数据来源说明

PoHW 内置题库中的部分题目整理自互联网公开渠道，经逐题校验、清洗与统一编号后
用于本项目的家庭学习场景；另有部分题目由本项目按小学课标参数化自编。
题目正文、选项与解析均不含站点水印、外链或抓取标记。

本项目为个人非商业的 Android TV 家庭实验，不上架任何应用商店、不用于商业用途。
我们尊重原作者与内容权利人的合法权益：**如相关内容涉及版权或其他权益问题，
请通过本仓库的 GitHub Issue 联系维护者**，核实后会及时删除或替换相关内容。

## 题目构成

| 类别 | 题数 | 说明 |
| --- | ---: | --- |
| 按课标自编（幼儿园～二年级） | 860 | 题面 / 选项 / 答案 / 解析均为本项目生成 |
| 互联网公开渠道整理并清洗 | 3873 | 逐题校验后保留，带难度分档 |

题库共 4733 道，含 `difficulty` 与 `difficulty_level` 字段，家长可设置难度倾向，
默认「不限」。`app/assets/quiz.db` 的 `meta` 表记录了版本戳、题数与来源说明。

## 与代码的关系

代码部分沿用项目 MIT 许可证；题库内容的权利归各自权利人所有，
不随 MIT 许可证一并授权。题库与代码一同通过
feature 分支 → Pull Request → 自动审核 → 合入 `main` 的流程合入，
tag 与 Release 由维护者指定。
