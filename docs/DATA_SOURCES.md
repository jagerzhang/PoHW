# 题库数据来源说明

PoHW 内置题库中的部分题目整理自互联网公开渠道，经逐题校验、清洗与统一编号后
用于本项目的家庭学习场景；另有部分题目由本项目按小学课标参数化自编。
题目正文、选项与解析均不含站点水印、外链或抓取标记。

本项目为个人非商业的 Android TV 家庭实验，不上架任何应用商店、不用于商业用途。
我们尊重原作者与内容权利人的合法权益：**如相关内容涉及版权或其他权益问题，
请通过本仓库的 GitHub Issue 联系维护者**，核实后会及时删除或替换相关内容。

## 题目构成

| 类别 | 说明 |
| --- | --- |
| 按课标自编 | 本项目参数化生成，主要用于 1–2 年级基础题 |
| 互联网公开渠道整理并清洗 | 逐题校验、按课标重打年级、修复英文单词空格后保留 |

题库共 **3876 道**，全部带 1–6 年级标签。`grade` 表示「最低适用年级」的保守下界，
并非精确年级：2,932 道原本只有 `知识点 7xxxxx` 数字占位符的题已按课标纲目逐题重定级，
补上真实纲目名并废止用难度系数反推年级的做法；无法确证的题标为
`syllabus_scope='generic'` 通用题，不参与教材单元过滤。

从 quiz-challenge 整合的 77 道题经过算式验算、去重与课标重定级，仅保留 PoHW 稀缺年级 /
运算组合，同样标记为「无教材版本」——该库本身没有教材版本、册次或单元字段。
`difficulty` / `difficulty_level` 也已按题面复杂度重分三档（原值是上游站点的噪声系数）。

家长可设置难度倾向，默认「不限」。抽题时只取不高于当前年级的题目，
避免低年级出现超纲内容。离线题库**不含出版社教材版本与册次**，
「学期 / 已学单元」只按课标纲目别名匹配，不代表任何教材版本的真实进度。`app/assets/quiz.db` 的 `meta` 表记录了版本戳、题数与来源说明；
重建与校验口径见 [QUESTION_BANK.md](QUESTION_BANK.md)。
